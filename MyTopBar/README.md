# MyTopBar 🌊

Modern, clean, and elegant top bar for GNOME Shell 45–51 inspired by macOS aesthetics and workflow.

## 🚀 Key Features
- **Automatic Theme Detection**: Instantly detects system dark or light mode and dynamically adjusts colors, contrast, battery rendering, and glassmorphism styling.
- **Smart Auto-Hide**: Automatically hides on fullscreen or maximized windows, cleanly coexists with minimized or background windows, and reveals upon moving cursor to the top edge.
- **System Menu**: Dedicated menu with quick access to system information, settings, lock screen, logout, and power options.
- **Active Application Title**: Displays the focused window's application name and title in real time.
- **Centered Clock & Calendar**: Customizable date/time format with direct integration to the native GNOME Calendar.
- **Spotlight Search**: Fast integrated file and application search accessible via `Super + Space`.
- **Hardware Status Indicators**: Interactive Wi-Fi menu, Bluetooth, GNOME Control Center, and high-definition Cairo vector battery indicator with charging state.
- **Floating or Edge-to-Edge**: Optional floating bar layout with rounded corners and margins.

## ⚙️ Preferences
```bash
gnome-extensions prefs MyTopBar@demonc
```
