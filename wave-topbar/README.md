# Wave Top Bar 🌊

Barra superior moderna, limpia y elegante para GNOME Shell 45+ inspirada en el diseño de macOS (sin llevar su nombre).

## 🚀 Características
- **Menú de Sistema**: Botón con acceso a *Acerca de este equipo*, *Configuración del sistema*, *Bloquear pantalla*, *Cerrar sesión*, *Reiniciar* y *Apagar*.
- **Aplicación Activa**: Nombre e icono de la aplicación en foco con acciones contextuales de ventana.
- **Reloj y Fecha Centrados**: Con formato personalizable e integración directa con el Calendario y Notificaciones de GNOME.
- **Búsqueda Spotlight**: Acceso instantáneo a la búsqueda global del sistema.
- **Centro de Control**: Acceso rápido a los controles de Wi-Fi, Bluetooth, volumen, brillo y energía.
- **Diseño Flotante o Edge-to-Edge**: Opción de barra flotante con bordes redondeados y márgenes.
- **Personalización Visual**: Temas oscuro, claro, negro o color personalizado mediante selector de color con rueda cromática GTK4.

## 📦 Instalación
```bash
./install.sh
```

## ⚙️ Preferencias
```bash
gnome-extensions prefs wave-topbar@demonc
```
